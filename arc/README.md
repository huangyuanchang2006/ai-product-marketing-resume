# 网站架构记录

## 首版建议

- Figma 灰模先确定求职视图的信息顺序。实现阶段将简历内容和页面组件分开，便于后续为不同机会调整作品顺序和介绍文字。
- 当前可从版本库内的静态内容开始，暂定把 `arc/` 用作架构记录。实现时再按选定的框架安排网站源码，代码和经筛选的公开素材可以一起用 GitHub 管理。

## Supabase 后续接入

- 在实现前区分变动频率：姓名、教育背景、精选经历通常可随站点版本更新。经常更新的作品或近况可以评估交给 Supabase。
- 内容先保留明确的边界，例如项目名、本人贡献、成果说明和证据链接。届时可逐类迁移，不必一起改动页面排版。
- 等确认第一项需要在线更新的内容及维护方式，再定表、存储和访问权限。当前未创建数据库或配置凭据。
