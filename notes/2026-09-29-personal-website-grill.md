# Personal Website: Grill / Discovery Notes
Date: 2026-09-29 · Goal: 把个人网站从“静态作品集”重新定义为一个动态、持续生长、连接我与世界的个人门户，并在接下来几天收敛到可搭建的方向。

## Summary / key decisions

- 三条早稻田祭作品已收到并核对原帖链接和官方嵌入代码。前两条作为主案例，「11.7 等你来喝」作为同组补充作品。
- 「冰块」和「One Last Sweet Stop」确认为用户主导，从创意、拍摄组织到成片、发布和数据复盘。Instagram 后台单条浏览分别为 1,406 和 2,175。新增本地合作与日语活动执行的证据。
- 首版新增三组证据：11 月开始的 CSSA 视频创作和 SNS 运营、Chambers 在东京的账号数据及原创流程图、Cosmoswork 实习的跨平台交付和质量检查。实习时间以本次 LinkedIn 截图为准，为 2026 年 8–9 月。
- 求职首版暂缓 3D 人像和贴纸导航。优先快速做出一页简洁、有个性的简历站，用核心经历、个人能力和可核对的数据支撑，并通过页面本身体现用户的设计判断。
- 岗位已收到：AI 产品市场活动实习生（日本市场）。补充信息明确，如果可驻日本，当地社群参与和拓展是重点，目标人群为 Marketers、Creators、E commerce sellers。
- 2026-11-21 更新：已经有一项真实的潜在实习机会。当前先做一份针对它的网页版简历，交付从 Figma 低保真灰模开始。岗位详情待用户发来，想呈现的信息已经在本地整理。
- 本地项目需要 `design.md`、`reference.md`、存放参考原件的 `reference/`，以及暂作架构记录的 `arc/`。后续用 GitHub 管理代码和迭代，并提前思考 Supabase 接入时机。
- 网站不再被限制为只有单一观众的 portfolio，而是一个 dynamic, always growing 的 personal portal。
- 主页初步设想：以自己的真人照片生成的 3D 模型为核心视觉（Tripo AI 生成、Blender 调整），旁边或周围呈现 Value Proposition。
- 模型脸部的 stickers 作为可点击入口，跳转到不同界面/内容分区；灵感来自小红书上的 AI Builder 项目，之后会复习其实现方式并尝试复刻、改造。
- 现有素材不止“项目作品”：还包括来时路、艺术资产、Minecraft 建造经历、社会实践/实习资产，以及这些经历背后的关系与背书。
- 新增一类重要资产：新航道老师采访你的直播。它不仅是可展示的视频，也是“从成为被采访者开始积累公共表达、知名度与信任度，未来再转向采访他人”的起点。
- 该采访原始素材仍保留；可自行剪辑成约 5 分钟浓缩版，放在个人网站上，并作为未来发送访谈邀约时的可信度证明。
- 初步内容资产候选：
  - 高一高中十大歌手比赛：班主任拍摄的视频、全体大合唱陪唱《Someone Like You》的现场记忆。
  - 艺术资产：初中（2021–2023）加入 Minecraft 建筑团队“阿尔萨斯工业 Alsace Industry”，参与“阿克斯城”史诗中世纪地图。
  - 若干个人 Minecraft 小型项目，其中一个有 Blender 渲染图。
  - 社会实践：宇宙 EBIKE 品牌内容实习，本地 Codex、ChatGPT 项目和 Obsidian 有多份工作记录，可选经确认的案例和官方社媒作品。
- 两张用户附图被记录为视觉参考素材：Minecraft 中世纪建筑的整体场景与建筑细节；它们不是额外的用户指令。
