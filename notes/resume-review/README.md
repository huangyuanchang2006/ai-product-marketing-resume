## 版式规格

桌面左右边距 72 px。报头左侧是中文姓名、斜体英文姓名、四项身份标签、定位、教育和语言成绩；右侧使用本人的樱花肖像。主案例采用三栏结构，左栏深蓝题签约占 22%，右侧分别放交付量和工作流。正文底色 #FCFBF7，题签 #193659，项目底色 #F0EFE9。案例外链可用键盘聚焦，减少动态效果时禁用箭头位移。

720 px 及以下切换单栏。390 px 手机上姓名和小幅肖像并排，四个标签按原顺序排两行，语言成绩在介绍下方。深蓝题签改为横条，交付量仍并列，AI 三步流程在下。肖像来自用户旧个人站素材，仅供本地选图评审；如确认公开发布，使用同目录已缩小并移除原始元数据的 portrait.jpg。

CSSA 先展示本人职责，再列两条作品和对应浏览数。个人账号的大数字缩至桌面 32 px、手机 30 px。早稻田祭现场运营与 OpenAI 活动桌面并列，手机连续排列；选课网站以简短项目收尾。
